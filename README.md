# Moodle ejercicios

Ejercicios del curso, organizados por día y una carpeta por reto.

## Día 1 — HTML base

| Carpeta | Contenido |
|---|---|
| `dia-1/dia-1-reto-1/` | Estructura base e index.html |
| `dia-1/dia-1-reto-2/` | Página de inicio con encabezados, listas, imágenes y enlaces |
| `dia-1/dia-1-reto-3/` | Página de tarifas con tablas y rutas relativas |
| `dia-1/dia-1-reto-4/` | Rueda Libre v0.1: tres páginas con menú y pie comunes |

## Día 2 — Semántica y formularios

| Carpeta | Contenido |
|---|---|
| `dia-2/dia-2-reto-5/` | Reestructurar las tres páginas con etiquetas semánticas, manteniendo su contenido y su navegación |
| `dia-2/dia-2-reto-6/` | Creación del formulario de reserva |
| `dia-2/dia-2-reto-7/` | Validación nativa a partir de reglas de negocio y formulario usable con el teclado |

## Día 3 — CSS

| Carpeta | Contenido |
|---|---|
| `dia-3/dia-3-reto-9/` | Hoja de estilos externa con variables CSS: paleta, tipografías y escala de espaciado |
| `dia-3/dia-3-reto-10/` | Estados de enlaces y menú (`:hover`, `:focus`, página activa) y estilo de botones |
| `dia-3/dia-3-reto-11/` | Modelo de caja (`box-sizing`), contenedor centrado, menú horizontal, portada, tarjetas, tablas y formulario |
| `dia-3/dia-3-reto-12/` | Componentes: botones, insignia "nuevo", botón de WhatsApp y clase `.visualmente-oculto` para accesibilidad |

## Cómo verlo

Abrir el `index.html` de cada reto en el navegador. Las demás páginas están en `paginas/`, las imágenes en `img/` y, desde el día 3, los estilos en `css/styles.css`.
